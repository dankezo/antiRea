# antiRea v2.7.1 深入解析

本版主题：三个通过了各自预注册实验室门槛的研究候选（HARVEST2 计划中的 C19、C22、C23）以可选启用的咨询信号形式发布，从其冻结的实验室检测器忠实翻译而来。下文每项内容都标注了证据类型：**经典单元**（在真实 harness 应用上运行的攻击）、**模拟**（带种子、可复现、生成器有记录）或 **unit**（测试套件证据）。未达到预注册标准的声称按失败如实写明，并附数字。

发布时套件：**621 个测试，619 通过，0 失败，2 跳过**（既有的 RSA-PSS 互操作跳过）。

## 第 1 部分 - 本版范围

2.7.1 是纯增补。三个新模块进入 `src/tier2-active/`，遵循与两个咨询先例（2.7.0 的 C6、2.7.0 的 C9）完全相同的纪律：可选启用（除非 host 构造该模块并向其馈送数据，否则什么都不运行）、仅咨询（每个信号和快照都带 `enforcement: "none"`；三个表面上都不存在任何拦截或裁决函数）、零运行时依赖、纯计算。没有其他 `src/` 文件导入它们（已用 grep 核实），因此默认路径不可能改变行为--而下面的经典发布轮次用测量证明了这一点，不只是靠 grep。

每个模块都是一个在实验室运行之前已用文字冻结的检测器的忠实翻译（实验室的 Step 0 / 设计文档），每个实验室结论都是预注册门槛下的 PASS-lab--误报线、检出线和 evader 单元都在任何数字出现之前锁定。翻译引入的偏差列于第 5 部分；没有一处偏差触及统计量、阈值或结论规则。

## 第 2 部分 - 群体盒信号 - C19（`createCohortBoxSignal`）

### 2.1 机制

目标形状：按轮换排班提取的 workforce--轮班 crew 的汇总活动以盒状波形重复，周期从数小时到数天（36 小时和 48 小时轮换是已注册的单元）。按身份和按会话的统计量看不见它；信号存在于群体的汇总速率之中。

检测器就是实验室冻结的 Step 0 统计量，未作改动。host 声明的群体的服务事件被装入 30 分钟的 bin，窗口为尾随 14 天（L = 672 个 bin）。Box Least Squares（Kovács、Zucker 与 Mazeh 2002）在 6 小时-168 小时的周期网格（x1.04 步进）上拟合盒状模板，分数时长 q 取 {0.03, 0.05, 0.08, 0.12, 0.18, 0.25, 0.35}，相位 bin 数 M = min(240, max(24, round(P/0.5)))；获胜盒的信号残差功率 S 随后被 Pont 等人（2006）的红噪声因子 β  deflate，β 由获胜盒尺度上的残差自相关估计（块数钳制在 n_b <= L/4），得到 S_β = S/β。显著性来自同一序列的 199 次按日分块 bootstrap 复制--零分布保留每日内部形状和昼夜节律，同时打断多日周期性--标记要求 p <= alpha（默认 0.01）。API：`observe(event)`、`evaluateCohort(cohortId)`、`snapshot()`；错误为 `CohortBoxSignalError`。

### 2.2 实验室记录

预注册门槛，按顺序运行（模拟；基底是 C15 实验室重新生成的合法流）：

- **门槛 1 - 在折叠候选的尸体上做回归。** 更早的 epoch 折叠候选（C15）正是在这一合法家族上以 9.80% 的误标率死去。C19 的统计量：**0/150 = 0%**，标准 1.5%。
- **门槛 2 - 红噪声的诚实度。** 合法群体上的 β：中位数 **1.345**（p90 1.52，最大 1.71），标准 2.5--deflate 是真实的，但并不夸张。Step 0 中轮班 herd 被标记 5/9（36 小时：3/3，周期恢复在约 36.4 小时；48 小时：2/3；24 小时：0/3，即预先声明的同日相位盲点--见 2.3）。
- **门槛 3 - 促销门。** 促销群体汇总速率的误标：**0/50 = 0%**，标准 2.0%。（harness 的促销尖峰是第 5 天的一次性事件，不是周期性盒--正是 BLS + 按日分块 bootstrap 被设计来忽略的形状；与在同一群体上烧掉 80% 的群体堆叠候选的对比正是要点。）
- **Step 1（检测器逐字冻结）。** 三个家族的误标均为 **0%**（VALID-RAND 0/150，VALID-CHUNK-POOL 0/50，SALE 0/50）。检出：SHIFT-36 **9/9**，SHIFT-48 **8/9**--唯一漏检与 Step 0 漏掉的是同一个 β = 4.27 复制，已逐事件交叉核实。Evader（去同步、斜坡、连续）全部被标记 **9/9**，且 evader 的实测代价约为零--检测器读的是汇总速率的形状，不是成员结构。成本 p99 每 identity-checkpoint **22.4 ms**，标准 50 ms。
- **预先声明的排除，精确复现：** 覆盖几何 herd（已 PARK 的 C11 形状）得分为 **0/54**--C19 不是 C11 的重启检测器--SHIFT-24 得分 0/9（2.3）。

SDK 中的 unit 证据（规模更小，机制断言）：三个合法群体未被标记，S_β 为 6.0-7.1（实验室中位数 5.5，最大 8.3--同一区间）；SALE 未被标记；SHIFT-36 和 SHIFT-48 被标记，获胜周期恢复在约 36/48 小时；SHIFT-24 未被标记，由测试固定为已注册的结构性盲点；已声明 stratum 永不被标记，而其统计量仍被计算并完整报告；求值是确定性的（对同一数据两次求值返回逐 bit 相同的 p）。手工测得的成本：每次 24 成员群体求值约 175-225 ms，每 identity-checkpoint 约 8-9 ms。

### 2.3 发布形态与硬性条件

选项：`windowDays`（14）、`alpha`（0.01）、`bootstrapReplicas`（199）、`declaredStrata`、`minCohortEvents`（100）、`maxCohorts`、`maxEventsPerCohort`。两个硬性条件是代码，不是文档：属于 host 声明 stratum 的群体被赋予 `"declared_stratum"` 状态，永不被标记（其统计量仍被计算--拥有真实 36/48 小时轮班表的 host 应声明它，而不是吞下标记）；且该统计量是纯群体的--表面任何位置都不存在按身份的分数，因此该模块中的任何东西都无法在没有另一渠道证据的情况下接入按用户的后果。

同日相位盲点值得单独一段，因为它是结构性的，不是参数性的。按日分块 bootstrap 重采样整日，因此周期恰为 24 小时且相位锁定于日的信号，按构造就位于零分布**内部**--任何阈值改动都无法恢复它，也没有提供任何改动。威胁模型包含同日对齐轮换的 host 需要另一个渠道；本模块覆盖的是 6 小时-7 天周期带减去同日对齐线。

## 第 3 部分 - 缺失质量信号 - C22（`createMissingMassSignal`）

### 3.1 机制

目标形状：一击即走的 herd--大量身份，每个只触碰表面恰好一次（一个身份一个 IP、一个页面，然后消失）。按身份的机制按定义是盲的：没有第二个事件可以累积。因此统计量位于表面一侧，而且它是本计划中最古老的估计量：Good-Turing 缺失质量。

对每个（表面 x 窗口）单元，m = f1/n，其中 f1 计算在该单元中恰好出现一次的身份数，n 是该单元的总触碰数。一击 herd 直接抬高 f1；合法表面保持低而稳定的 singleton 份额。两个尺度：D1（一天，主要）和 D7（一周，辅助--由 7 天总量重新计算，绝不是日比率的平均）。单元只有达到事件下限（`minCellEvents`，默认 200）才被评分；低于下限的单元被计数并报告为 `below_floor`，从不评分。评分是单侧、含并列的 conformal，相对于 host 拟合的合法参考池：p = (1 + #{ref >= m}) / (N + 1)，在 D1 以 p <= `alphaDay`（0.02）、在 D7 以 p <= `alphaWeek`（0.05）标记。API：`observe(event)`、`fitSurfaceCalibration(surface, scale, cells)`、`evaluateSurface(surface, scale)`、`snapshot()`；错误为 `MissingMassError`。

### 3.2 实验室记录

预注册门槛（模拟，harness 表面；绑定表面 UNION = 资源 id 200..1999）：

- **Step 0，重叠门。** 在 H = 200 个一击身份/天的设计点上，分离是完全的：D1 合法 p50/p99 = 0.0839/**0.1259**，herd p05/p50 = **0.2238**/0.2554--**重叠 0**；D7 合法 p99 = 0.00151，herd p05 = 0.1815--**重叠 0**（D7 在每种 herd 规模下重叠均为 0；D1 在 H50 时仍以 0.324 的带重叠通过）。单独看 DEEP 和 RARE 表面也以 0 分离。
- **Step 0，viral 门。** D1 **0/168** 个 viral 周单元被标记，D7 0/24--附带构造警告，带入第 6 部分（实验室的 viral 群体是完整 persona 的新访客，不是只看一页的 drive-by 陌生人）。
- **Step 1（检测器冻结，种子全新）。** 误标：VALID 在 D1 为 **1/280 = 0.36%**（D7：2/40 = 5.0%，在该池规模下属描述性），SALE **0/140**，第二周 VIRAL **0/70**。检出：100、200、400 个一击身份/天的 herd 在两个尺度上均被标记 **100%**（H200：D1 84/84 + D7 12/12）；连 H50 也被标记 84.5%（D1）/ 100%（D7）。Evader：EV-BURST（1,400 个身份压缩进一天）在其日单元和周单元上均被标记 3/3；EV-REUSE-MIX（一半一击、一半 3 次触碰）仍被抓住 **39/42 = 92.9%**；EV-REUSE-2（每个身份复用 >= 2 次）被标记 **0/42**--按构造完全盲（3.3）。成本 p99 每单元 **0.248 ms**，标准 50 ms。

SDK 中的 unit 证据：一个汇总的 40 单元合法日集合恰好产生 **1 个名义标记**（2.50%，低于实验室在其 Step 1 设计中锁定的 3.0% 标准--被标记的单元位于 m = 0.1056，而 TRAIN 最大值为 0.1025，p = 1/61 <= 0.02 的 alpha：conformal 恰好按其名义率行事，如此断言，而不是被调到零）；SALE 实测单元 0/5；H200 herd 在两个尺度上被标记；EV-REUSE-2 不被标记，机制被直接断言（n 增长 400 时 f1 保持不变）；EV-REUSE-MIX 和 EV-BURST 被标记；低于下限的单元即使 m = 1 也不被评分；未校准的表面从不被标记；迟到的事件被拒绝，已关闭的单元此后逐字节不变。

### 3.3 发布形态与硬性条件

表面属于 host：`surfaceOf(resourceId)` 把资源映射到表面名（实验室的 id 区间是 harness 伪影，**没有**被硬编码）。没有 `surfaceOf` 时，模块处于 DISABLED--与 C9 的分层法则同属一个硬条件家族。窗口锚定在 `windowStartMs`（默认 0），且不追溯：属于已关闭窗口的事件被拒绝为 `late_window`，从不重写已报告的单元。

复用盲点是该模块的定义性限制，而实验室结论建立在候选运行**之前**注册的一条条款之上：一个有纪律到复用每个身份 >= 2 次的 herd，会把自己交给那些计量复用的渠道--记录并集、输入空间覆盖（C6）和 motif 渠道。这种关联税是一个设计论证，不是测量：没有任何实验室运行端到端地评过这个组合，本版也不声称它。单独部署此信号的 host，将完整拥有 >= 2 次触碰的形状。

## 第 4 部分 - 生命周期群体信号 - C23（`createLifecycleCohortSignal`）

### 4.1 机制

目标形状：bust-out。账号被创建，在变老的同时保持沉默，然后在一次同步爆发中被一起激活--老化账号 bust-out 与沉睡账号 AML 的欺诈模式，转用于提取。已注册的设计决定是**不**猎杀老化阶段（它沉默且与合法沉睡无法区分）；门设在爆发和它之前的 staging 上。

返回点是前面有至少 7 天可观察间隙（`returnGapMs`）的事件。每个返回点携带相对于身份**自身**历史的两个比率：ρ = 间隙 / 可观察年龄，ν =（返回后 72 小时内的新增记录）/（返回前新增记录 / max(1，返回前跨度 / 72 小时））--返回前新颖度为零的身份没有定义的 ν；该点被排除并**计数**（`returnPointsExcluded`），从不被静默丢弃。成员在返回点处触发（FIRES）当合取成立：它在 [rp, rp + 24 小时）内触碰了 host 声明的 staging 带，ν >= 4，且一个主导 topic 覆盖其 [rp, rp + 72 小时）内新增记录的 >= 0.5。群体在至少 `minFiringMembers`（默认 6--实验室锁定的 6/24）个成员在同一日历日（首次 staging 触碰的 UTC 日）触发时被标记。API：`observe(event)`、`evaluateIdentity(identity)`、`evaluateCohort(cohortId)`、`snapshot()`；错误为 `LifecycleCohortError`。

### 4.2 实验室记录

harness 的原装合法生成器根本产生不了老化返回者（实测：14/28/90 天视野下 3,600 个身份中 >= 7 天的返回为 0 次；观察到的最长沉默是 6.02 天），因此 returner 和 launch 群体是由未修改的生成器自身的阶段经声明式组合构建的--组合在任何运行之前已在实验室 Step 0 文档中完整披露，与 C22 中 viral 单元受到的处理相同。

- **Step 0，LAUNCH 门（群体）。** 一次合法发布把老用户大规模拉回：**0/30 个群体被标记**（杀线 >= 2/30），而 staging ∧ 同步合取在 **720/720** 个返回点上触发--该门不是空的；合法发布流量所不携带的是合取中爆发 ∧ funnel 的那一半。
- **Step 0，身份门（RETURNER）。** 恰好在界线上通过：**12/600 = 2.000%**，杀线为 > 2%，且按种子看很脆弱（3.0% / 0.5% / 2.5%--三个种子中有两个单独越线）。ρ 轴对 returner 没有分离力（ρ 在各处都 ≈ 0.85-0.91）；锁定的区域实际上就是 ν >= 4 这一个单轴门。
- **Step 1（检测器冻结，种子全新）。** 群体误标：LAUNCH **0/60**，VALID **0/100**，SALE **0/50**--210 个合法群体，没有一个成员误触发。检出：BUST-COHORT 被标记 **18/18**（标准 15/18），触发成员中位数 24/24。成本 p99 每身份 **0.068 ms**。
- **身份复检--一次已注册的降级。** Step 1 的确认重新测得身份误报为 **58/2,000 = 2.9% > 2% 标准**，触发了运行**之前**在设计中锁定的后果：身份特征仅作描述。它有完整的检出（BUST-SOLO 返回点落在区域内并以描述方式触发，300/300）--它死于误报，不是死于盲，而 PASS 丝毫不借它的力。
- **Evader 测量。** EV-DESYNC 按偏移分解：偏移 1-3 天被抓 36/51（SGI 签名），**偏移 4-6 天完全盲 0/45**，偏移 7-14 天在身份层面盲，但 50/120 仍通过自 staging 触发（4/9 个群体被标记）。EV-NOSTAGE（没有注入 staging）本被预期为盲，但**并不盲**：被标记 8/9，因为一次强爆发自身就会在约 37% 的成员身上触碰 staging 带（79/79 次触发都是自生成的）--staging 合取是漏的，两个方向都漏（4.3）。EV-SLOW 按注册为盲（ν ≈ 1.5；那是预算/CUSUM 的领地）。

SDK 中的 unit 证据：bust 群体被标记，24/24 成员在返回日触发；一个有同步晨间 staging 触碰的 LAUNCH 群体触发 0/24 个成员且不被标记；5 个触发成员停留在 6 的阈值之下；一个单独的 bust 返回点落在区域内，其组成部分被报告，且**不存在**标记字段（由 `'flagged' in scores === false` 断言）；偏移 5 天的 EV-DESYNC 触发 0/24，由测试固定；ν ≈ 1.6 的 EV-SLOW 不触发；缺失声明产生 `undeclared`，每个缺失的 term 精确地在该 term 上为 null。

### 4.3 发布形态与硬性条件

两个声明法则是代码：没有 staging 声明（`isStagingResource` 或 `stagingResourceIds`）**并且**没有 topic 映射（`topicOf`），`evaluateCohort` 返回 `"undeclared"` 状态且永不被标记--合取的各个 term 是 host 的语义，模块拒绝替它编造。降级也是代码：`evaluateIdentity` 返回每个返回点的分数（ρ、ν、`inRegion`、合取的组成部分），模块中身份层面的任何位置都不存在 `flagged` / `verdict` / `decision` 字段--一个测试断言它的不存在，以便未来的重构不能悄悄重新武装实验室已经降级的特征。

staging 的泄漏是双向的，host 应在接入后果之前读完这一段：该通道也抓住从未 staging 的 bust（好事），但一个合法的、繁重的、同步的提取团队--一个按计划做着恰恰是爆发形状工作的已声明审计团队--可以穿过这道门（实验室在那一侧只测了一个正常浏览的 launch 单元）。缓解办法是现成的一条：已声明的受保护群体是 host 已经拥有的注册决定；本信号不替代它。

## 第 5 部分 - 与实验室记录的偏差（L1-L5）

写在构建报告中，在此重复以使本深入解析自成一体。五处偏差无一触及统计量、阈值或结论规则；每个发布默认值都等于实验室锁定的数字（C19：网格 / q 集 / β / 199 次复制 / α 0.01；C22：下限 200，α 0.02 / 0.05；C23：7 天间隙，24 小时 staging 窗口，72 小时爆发窗口，ν >= 4，funnel >= 0.5，同步 6）。

- **L1 - C19 的 bootstrap 种子。** 实验室从按群体身份播种的独立流中抽取每个复制。SDK 从装箱序列本身的 FNV-1a 哈希播种**一个**流：零结构相同（日块有放回抽取），具体抽取不同，因此同一数据上的 p 在细节上与实验室不同，而统计量、deflate 和标记规则完全相同。原因是实验室不需要的一个 host 属性：求值是所保留数据的纯函数且可复现（确定性由测试固定--两次求值返回逐 bit 相同的 p）。
- **L2 - SDK 测试中 C22 的合法单元标准。** 实验室自己的 Step 1 设计在运行**之前**把先例的 2.0% FP 标准换成了 3.0%，因为以检测器 2% 的名义 α，280 个单元上 2.0% 的标准按构造就是抛硬币。SDK 测试按同一 3.0% 标准断言，并断言确切的名义计数（1/40）。检测器的 α 是实验室的，未改动。
- **L3 - 窗口与时间锚。** 实验室把一切锚定在其群体的 t = 0。SDK 做了翻译：C19 评一个以群体最新事件结尾的尾随 14 天窗口（最后时刻被钳入最后一个 bin）；C22 把日/周单元锚定在 `windowStartMs`；C23 的"日历日"是 UTC 日 `floor(ts / 86,400,000)`，而非相对于群体的日。每个模块的头部都写明其锚。
- **L4 - C19 的群体规模。** 实验室锁定 N = 24。SDK 评任何 host 声明的群体，仅由 `minCohortEvents` 把关--群体构成是 host 的声明，这正是构建被赋予的范围。
- **L5 - 时间戳纪律。** 三个模块都把非有限的 `ts` 或 |ts| > 8.64e15 在触及任何状态**之前**拒绝为无操作 `{ status: "invalid_ts" }`（herd 模块的 F-21 先例），并对其他格式错误的字段抛出具名错误（C9 先例）。实验室没有这样的单元--它的数据总是干净的；这是 SDK 树的纪律，不是统计偏差。

## 第 6 部分 - 2.7.1 不声称的内容

- 三个信号中的任何一个都不带来执行：每个都带 `enforcement: "none"`，不暴露拦截函数，也不接入任何默认路径。经典轮次证明的是默认路径**不变**--它对新模块什么都没测（它们不在 harness 中）。
- C19 不做按身份的归因（按构造是纯群体的），不检测同日对齐的轮换（24 小时盒位于其自身的 bootstrap 零分布之内，实验室 0/9），也不检测覆盖几何（实验室 0/54--已 PARK 的 spectral 观察保持 PARK）。
- C19 不对 β 作保证：当残差在盒尺度上保持相关时，β 会过度 deflate 并吞掉真实信号（漏掉的 48 小时复制，β = 4.27）。池化 β 变体需要新的研究注册，不是补丁。
- C22 对有复用纪律的 herd 不作独立覆盖声称（EV-REUSE-2，实验室 0/42）：PASS 建立在预注册的关联税（并集 / C6 / motif 渠道）之上，而这个组合从未被端到端测过。
- 本版任何地方都没有 drive-by viral 的测量：对 C22 重要的那个单元（一个陌生人恰好查看一个深页然后离开，把 f1 泵入深表面）在真实 host 日志上的任何实验室运行中都不存在。有这种流量形状的 host 必须先自行测量，才能把 C22 的标记当作 herd 证据。
- C23 不做身份层面的裁决：身份特征是按实测降级的描述（复检 FP 2.9% > 2%），把它的分数读作标记会重新制造那个比率。C23 也不覆盖偏移 4-6 天的去同步（0/45），也不覆盖慢速爆发（预算/CUSUM 的领地）。
- C23 不作干净的 staging 语义声称：staging 合取是漏的（约 37% 的爆发成员会自己触碰该带），因此一个标记是关于爆发 ∧ funnel ∧ 同步的证据--而一个合法的同步繁重提取团队可以穿过同一道门。受保护群体注册表，而不是这个统计量，才是缓解办法。
- 本版任何内容都没有真实流量校准。三个模块都在**一个**模拟合法生成器家族上验证（外加为该生成器产生不了的群体所作的声明式组合）；实验室规模的误报池（280 个单元、210 个群体、2,000 个复检身份）**没有**在 SDK 测试中按原规模复现--SDK 测试以更小的规模移植决定性单元，只在样本量承载得起的地方断言汇总比率（C22 VALID）。CUSUM 的 farm 拟合仍受日历门控（最早的诚实拟合约在 2026-11-16，之后是留出集结论），2.7.1 中的任何东西都不移动它。
