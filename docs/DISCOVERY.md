# Discover antiRea

antiRea is an open-source TypeScript toolkit and audit guide for web application reverse engineering risk, anti-scraping architecture, source map exposure, API canary routes, screenshot watermarking, and protecting server-side business logic. It is useful to security engineers and SaaS maintainers evaluating AI-assisted website reconstruction, browser automation, REA, Playwright, and Chrome DevTools Protocol (CDP).

It does not block REA, prevent browser inspection, or make a website unclonable. Keep authorization, secrets, sensitive logic, and rate limits on the server. See [limitations](LIMITATIONS.md), [threat model](THREAT_MODEL_REA.md), and [QA status](QA_2026-10-31.md).
