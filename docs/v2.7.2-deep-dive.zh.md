# antiRea v2.7.2 深入解析

本版主题：五个通过了预注册实验室标准的研究候选（HARVEST2
计划中的 C27、C30、C35、C29 与 C39）以可选启用的咨询
信号形式发布，面向那些慢速形态--持续的收割者、机器节律
的轮询者、枚举遍历者、在上限之下聚束的校准者，以及被再
发布的衍生总计。
每个候选在纳入之前，都在发布的实现上用全新种子重新测量
过；其中一个通过了实验室标准的候选--R14-v2b（谱系监视
lineage watch）--在该复测中失败并被排除；第 7 部分是
它的记录。下文一切内容都标注了证据类型：**经典单元格**
（在真实 harness 应用上运行的攻击）、**模拟**（带种子、
可复现、生成器有记录）或 **unit**（测试套件证据）。未达
到预注册标准的说法按失败记录，并附数字。

发布时套件：**682 个测试，680 通过，0 失败，2 跳过**
（既有的 RSA-PSS 互操作跳过）。

## 第 1 部分 - 本版范围

2.7.2 是叠加式发布。五个新模块进入 `src/tier2-active/`，
遵循与咨询先例（2.7.0 的 C6/C9、2.7.1 的 C19/C22/C23）完
全相同的纪律：可选启用（除非 host 构造模块并向其喂数据，
否则什么都不运行）、仅咨询（每个信号与快照都带
`enforcement: "none"`；五个表面中没有任何一个存在拦截或
裁决函数）、零运行时依赖、纯计算。没有其他 `src/` 文件
导入它们（已用 grep 核实），因此默认路径不可能改变行为
--而下面的经典发布轮次用测量证明了这一点，而不仅仅靠
grep。

每个模块都是一个在实验室运行前就已书面冻结的检测器的忠
实移植，每个实验室裁决都是在预注册标准下的 PASS-lab。其
中一个还携带在本版构建之前以独立冻结注册形式登记并测量
的升级，遵循常设规则：差一点通过的候选得到一条修补路径，
永远得不到放宽的标准--C39 的跨版本证据汇集与 >= 3 步变
换链（第 6 部分）。移植引入的偏差列于第 8 部分；没有一条
触及裁决规律，而其中最大的一条（C27 的观测时钟，D2）
被量化了，而不是被悄悄吸收。

**经典发布轮次（仅受保护侧；2.6.0 运行器及其锁定常量不
变；未保护侧按常设发布规则不重跑）。** 裁决：没有新增回
归--每个单元格在每个有裁决分量的数字上都与 2.7.1 基线
一致。

## 第 2 部分 - Shrink-slope 信号 - C27 (`createShrinkSlopeSignal`)

**机制（冻结的实验室规则，不加发明地移植）。** 估计量是
θ_i：身份 i 在其后期窗口--其自身观测的第 31-90 天--平均
每天的新记录数，(C(90) - C(30)) / 60。每日新颖性按
Normal(θ_i, σ_i²) 建模，σ_i² 是该身份在窗口内自身的日间
方差。一个稳健的经验贝叶斯先验--混合
0.9·N(m, τ²) + 0.1·N(m, (3τ)²)，(m, τ) 用中位数/IQR 估
计，并从 τ² 中减去中位测量噪声--按**层**拟合，层是该身
份在参考人群中第 1-30 天总请求量的三分位。阈值 c_s 是该
层内参考人群原始 θ̂ 的第 99 百分位。当混合后验
P(θ_i > c_s | y_i) >= 0.975 时身份被标记，后验在对数空间
计算（实验室自身的溢出修复是冻结规则的一部分）。

**证据（模拟）。** 实验室，预注册：两个步骤中 VALID 误
标 0/1,200、SALE 误标 0/1,200；平台敏感度在每天 K = 7/20/50
条新记录时均为 100%；EV-RAMP（7 到 20 的线性斜坡，后期窗
口 θ ≈ 17）为 100%，标准下限 50%；先验在 5%/15% 污染下
误标保持 0.00%。在全新种子（20267501+）上、参考经模块自
身的 `fitFromDailySeries` 拟合的 SDK 复测：**0/1,200 与
0/1,200；K = 7、20、50 时平台均为 300/300；EV-RAMP
300/300；EV-FRONTLOAD 0/300；两个污染级别均为 0.00%；每
身份评分 0.003 ms。**有一条评分输入偏差被测量而不是被隐藏
（第 8 部分，D2）：模块的日时钟是身份相对的，host 通过
`asOfTs` 提供"现在"--复测的草稿运行在没有它时让
312/1,200 个 VALID 身份处于 `insufficient_history` 状态，
而当 `asOfTs` 设在每个身份的第 90 天之后时，每个单元格
的未评分计数均为零。

**已声明的限制。** 分离之所以完美，是因为实验室的合法新
颖性会硬性饱和；一个能连续 60 天每天持续读到 >= 7 条真
正新记录的真实读者是一个未测量的误报形态，该结论仅具内
部有效性。EV-FRONTLOAD 是后期窗口估计量的结构性盲点：一
个在前 30 天拿走一切、之后沉寂的身份，其 θ_后期 ≈ 3，
正确地不被标记--它买到的暴露是预算层土地上的 30 天全速
期。比窗口年轻的身份从不被评分
(`insufficient_history`）；层是请求量代理，不是真实的用
户原型。

## 第 3 部分 - Watchlist 信号 - C30 (`createWatchlistSignal`)

**机制。** 对每个（身份，资源）对，取其在尾随 90 天窗口
内的不同访问日期；一个资源在访问日期 >= 5 天时合格；其
间隔 CV 是连续访问日间隔的 sd（间隔）/mean（间隔）。身份
的统计量是其合格资源（身份需 >= 3 个合格资源）间隔 CV
的**中位数**；当统计量 <= τ 时标记。τ 默认为实验室的冻
结值 0.6130895965797241（TRAIN 人群的 q01)，并可通过
`fitThreshold` 用 host 的参考轨迹以同样的 q01 构造重新拟
合。

**证据（模拟）。** 实验室：VALID 误标 1.33% (16/1,200)、
SALE 0.83% (10/1,200)，标准锁定在 2%；无抖动轮询者标记
120/120；对每个间隔施加 ±100% 抖动的轮询者在间隔周期 1
和 2 时标记 100%。审稿轮次提出了一个未测量的单元格--事
件驱动检查者--它随后被登记并作为构建前的扩展测量：误标
4.50%，与习惯性检查者群体同一量级。全新种子上的 SDK 复
测：**VALID 1.67% (20/1,200)、SALE 1.17% (14/1,200)、
HABITUAL 5.42%、EVENT 5.33%、轮询者 120/120、抖动单元格
100% / 100%**--每个带标准单元格都守住了锁定标准，两个
描述性单元格（HABITUAL、EVENT;以 n = 1,200 对实验室的
600 运行）与实验室的 4.83% / 4.50% 处于同一区间。端口
的区间 CV 除以总体计数，与实验室代码完全一致；不存在
sd 约定偏差。它唯一的窗口偏差（尾随 90 天窗口结束于身
份最近的事件日，而不是实验室的固定全轨迹窗口--第 8
部分，D3）在实验室的 90 天轨迹上选出同一组访问日。

**已声明的限制。** 习惯性与事件驱动检查者是日尺度的误标
成本（约每二十人中一人）--以这一分辨率看，他们的间隔
确实近周期。亚日轮询在日分辨率下不存在，按构造超出范围。
指数间隔轮询者在实验室锁定的税收定义下支付零税，仅通过
其陈旧资源尾巴被抓住（实验室测得约 13.5%）--作为观察报
告，而不是检出结论。

## 第 4 部分 - Decoy tripwire - C35 (`createDecoyTripwire`)

**机制。** 没有统计量。host 声明诱饵资源--id 列表或谓词
--它们被放置在每个发现表面之外（导航、站点地图、列表、
搜索索引）。模块计数它看到的请求（分母）并记录对诱饵的
触碰；身份在触碰了至少一个诱饵时即被 `flagged`。没有诱
饵声明时模块处于 DISABLED：它什么都不记录，每个调用都
报告禁用状态（C22/C9 硬条件先例）。

**证据（模拟）。** 实验室：合法浏览在 1,200 个身份 /
1,115,408 个请求中触碰了 60 个采样诱饵中的 0 个；枚举敏
感度（90 天内触碰 >= 1）在采样放置下的全部九个单元格
（K = 7/20/50 × 排列、顺序、降序）均为 1.000；随机放置确
认--单独登记，因为审稿轮次认定放置正是 PASS 所凭依的结
论--在每次重复重新抽取放置的情况下复现了全部九个单元格
的 1.000，并且一个带宽松跳过规则的学习型规避者仍然 100%
触碰（平均触碰次数按 K 为 18.62 / 52.42 / 60.00)。全新种
子上的 SDK 复测、触碰由模块自身计数：**NAV 误标 0/1,200
个身份，对应 1,116,264 个请求；枚举遍历者在 540/540 个单
元格被标记（每个 K、每种顺序均为 180/180）；学习型规避
者在每个 K 均为 60/60（平均触碰次数按 K 为 18.40 / 52.62
/ 60.00，对比实验室随机放置运行的 18.62 / 52.42 / 60.00）**。

**已声明的限制。** 触碰是一个枚举事件，不是意图裁决--
后验属于 host 自身的合法枚举构成（它自己的爬虫、合作伙
伴索引器、QA 扫描）。运维条件是结论的一部分：随机放置
是标准配置；可学习的放置模式是一个指纹；而泄漏到任何发
现表面上的诱饵会彻底杀死信号（实验室的故意泄漏单元格：
普通爬虫在第一遍就触碰了 60/60)。

## 第 5 部分 - 聚束监测器 - C29 (`createBunchingMonitor`)

**机制（冻结的实验室规则，不加发明地移植）。** Host 知道
它执行的上限；问题是人群的每日新颖性计数是否堆在该上限
正下方。对于一个候选缺口 n，模块构建按身份-日计的新颖记
录直方图，在环形区域 [n-3, n+2] 之外对计数对数拟合 5 次
多项式，并相对于该反事实测量窗口 [n-3, n) 内的超额质量
B，其标准误来自基于平滑拟合的参数自助法（200 次 Poisson
再抽样）；输出是每个被请求缺口处的 z。Host 要么喂原始观
测（`observe`--模块自己按身份 × UTC 日 × 资源计算新颖
性），要么喂预聚合的每日新颖性（`addDailyNovel`）。咨询上
限是结构性的，在实验室设计中预注册：任何输出都没有身份
级 API，也没有按身份的裁决字段--这个统计量是人群尺度的
校准仪表，永远不是关于单个账号的证据。低于
`minIdentityDays`（默认 2,000 个 identity-day）的人群报告
为未评分，缺口必须是 [4, 60] 中的整数（第 8 部分，D6）。

**证据（模拟）。** 实验室，预注册：在保存的合法与 sale
人群上，缺口 {10, 20, 25, 50} 处正向安慰剂 z <= 2.17（没
有缺口碰到锁定的 +3 标准）；在一组全新合法种子上，安慰
剂最大值是 24 项测量中的 1.55。植入的阳性对照--人群的
2% 被替换为目标新颖性 12-28/天、硬性在 C-1 处封顶的校准
者--在上限 15 下 z = 36.97 触发，当上限移至 25 时，超额
质量迁移到新缺口下方的窗口，z = 29.47，而旧窗口下方的质
量塌到其上限-15 时数值的 25% 以下。全新种子（20267601+）
上的 SDK 复测、模块独立编译并经 `addDailyNovel` 喂入：
**24 个合法/sale 单元格中安慰剂 z 最大值 = 2.05，没有单
元格碰到 +3；阳性对照 z = 36.97，迁移 z = 29.47，精确复
现实验室；迁移单元格中 15 以下的超额量从 2,104.9 降到
-396.2（比率 -0.188）**。作为超出复测单元格的移植保真检
查，把实验室保存的合法直方图本身喂给模块，复现了实验室
打印的 z/B/SE 的每一位数字。

**已声明的限制。** 被测的对照是硬校准者--死停在 C-1。
真实校准更软（概率性遵从、多个重叠阈值）且给出更弱的信
号；该形态未被测量，结论止于 harness 基底上的硬校准加迁
移。估计器对多项式阶数与环形区域选择的敏感度已在实验室
设计中声明，但从未量化；当一个大堆积存在时，反事实也会
向缺失方向扭曲（在堆积的另一侧，安慰剂 z 低至 -5.69）--
这不产生假的聚束警报，但意味着拟合的反事实在远离缺口时
是不精确的。该统计量需要大人群--数据下限是模块自身的。
不知道阈值的慢速遍历者按构造不会聚束，处于结论之外。

## 第 6 部分 - Value watermark - C39 (`createValueWatermark`)

**机制。** 对于 host 发布的一个衍生版本--按记录的（数量
q、单价 p、总计）三元组--标记器为每条记录计算 T = q·p,
并按量级放置计算一个带密钥的余数 a: T >= 20,000 时
a = gU + 10·gT + 100·gH; 2,000-19,999 时为 gU + 10·gT；低
于 2,000 时仅 gU，其中每个 g ∈ {0..6} 都由密钥、版本和记
录 id 导出（实验室盐值：个位 0、十位 7919、百位 104729)。
发布的总计为 T + a（失真在第 6 部分的证据中测量）。验证解码 â = round（已发布 - q·p)，用 divmod 把
它拆成三个尺度，并在一个尺度在其合格集上的匹配通过
R-ADAPT（>= 3 个匹配且匹配率 >= 30% 且 >= 二项均值 + 8 SD,
p = 1/7；百位尺度另需 >= 50 条合格记录）时确认该尺度。版
本裁决是各尺度的 OR。组总计按成员余数的精确总和验证
（50 组中 >= 5 组）。验证器还跨它检查的每个版本累积低层
的（匹配，合格）计数，`pooledLowStatus()` 对汇集计数应
用 R-ADAPT--跨版本汇集升级，在本版构建前单独登记并测量
（在实验室中，汇集确认在预先锁定的门限规模 80 个版本时
达到 94%，汇集中位 n ≈ 418，汇集误确认 0%）。

**证据（模拟）。** 实验室 SUPREME 注册：全部 15 项检查误
确认 0%；组合门在 18/18 个单元格以 100% 通过，包括 ±1 噪
声和两步变换链；在本版构建前测量的链扩展以 100% 确认了
7/7 条 3-4 步链条（每条含取整步骤的链都在更高尺度上得到
确认，正如预先声明）。全新种子上的 SDK 复测（每单元格
200 次重复）：**精确误确认 0/200、四舍五入到百位 0/200、
错误密钥 0/200；±1 噪声下确认 200/200、取整下确认
200/200、两步链下确认 200/200；组总计不是复测单元格--
它们由模块的 unit 测试覆盖（50/50 个已标记组确认，诚实组
不确认）；重新计算对照 0/200；汇集误确认
0/200；80 个小版本在噪声下汇集确认 180/200
(90.0%)--正好压在预注册的 >= 90% 标准线上：一次薄弱的
通过，如实记录，不向上取整**。发布标记器的失真：中位数
0.260%, p99 2.34%（实验室：中位数 0.229%, p99 2.18%）。

**已声明的限制。** 从分量重新计算会按构造摧毁余数--水
印证明一个总计经过了 host 的标记发布路径，而重新计算单
元格在实验室和 SDK 中均按设计确认 0%。知道完整配置（密
钥、盐值、放置）的对手可以伪造或剥离标记；该单元格同样
读作 0%，是一条声明的边界，而不是抵抗结论。交易价格与
发票总计超出范围--只有衍生的再发布总计被标记。跨两个不
同再发布者的链条，以及跨相关（非独立）周期的汇集，在任
何一轮都仍未测量。

## 第 7 部分 - 未发布的候选 - R14（谱系监视）

R14 追问由共同模具铸造的账号团队，能否按其特征档案分
组：特征距离上的 UPGMA 平均链接聚类，在模块自行校准的阈
值处切割。它的实验室记录是 PASS：v2b 规律（切割按扁平人
群零假设选择，错误合并预算 <= 1%）恢复了植入的家族，而
构建前的稳定性注册在五个全新种子块上守住了裕度（合并
CLEAN ARI 0.782，各块 0.768-0.795，扁平 FMR 每块
<= 0.614%，全部五次独立校准都重选 h_b = 0.32）。一个跳过
失败对的混合变体在同种子成对比较中测得相对纯规律恰好
+0.000，仅保留为实验室记录。

SDK 移植未通过锁定的复测，失败点在校准阶段，不在聚类阶
段。在任何固定阈值下，移植的划分与实验室逐位一致（用共
成员矩阵核实：0 个不一致对）。不同的是切割所依据的零假
设：实验室在生成器抽取的扁平人群上校准（特征独立、边际
均匀），而发布的模块无法运行 host 的生成器，因此移植在
观测人群本身上逐坐标置换特征。在一个有谱系结构的人群
上，两个零假设不等价：类别边际把大量质量堆在奠基者取值
上，数值特征聚集在起源点附近，于是两个独立置换的成员比
在扁平零假设下更常共享类别特征、且在数值上坐得更近。任
何给定阈值处的校准错误合并率因此更高，<= 1% 的选择规则
选出更低的切割点--在结构化单元格上 h_b 为 0.24-0.28，
实验室为 0.32--而恢复能力在敏感度一侧付出代价。在全新
森林上（种子 20267201+，每单元格 40 片，n = 48）：**合并
CLEAN ARI 0.622，对锁定标准 0.75；EV-SWITCH 0.439，对
0.50；EV-MERGE 0.527 与诚实扁平 FMR 0.645% 通过了各自的
标准**。在扁平人群上，移植以 0.32 为主导值进行选择，其
FMR 与实验室一致--偏差恰好在机制预测它应该消失的地方
消失，这正是缺陷在零假设而不在聚类的证据。

按常设发布规则--标准在见到数字后永不放宽，任何候选都
不被强行塞进发布版--R14 不在 2.7.2 中发布。它的 PASS-lab
作为实验室记录保持不变；失败的是本移植关于它在自校准表
面上守住实验室数字的说法。一条改变校准机制的修补路径
（边际拉平的置换零假设，或在 host 提供的已知扁平参考人
群上校准）需要其自身带全新种子的冻结注册；它不是对本版
的修补。

## 第 8 部分 - 相对实验室记录的偏差

- **D1 (C39，标记导出）。** 实验室从其带种子的生成器流中
  抽取 g; SDK 从（密钥、版本、记录 id、盐值）的带
  murmur 型终混的 32 位 FNV-1a 哈希导出 g, mod 7--不同的
  流；{0..6} 上的分布形状等同，放置与 R-ADAPT (p = 1/7)
  不变。测得的效果：失真中位数 0.260% / p99 2.34%，对比
  实验室的 0.229% / 2.18%，且每个带标准单元格都复现（第 6
  部分）。
- **D2 (C27，观测时钟）。** 实验室在人群的绝对日索引上评
  分；SDK 把身份自身第一个被观测事件日（UTC）设为第 1
  天，host 通过 `evaluateIdentity(identity, asOfTs)` 提供
  "现在"。约 15% 的 harness 合法身份其首个事件在第 0 天之
  后，约 26% 的事件跨度小于 90 天；没有 `asOfTs` 时，它们
  读作 `insufficient_history`（复测的草稿运行：312/1,200 个
  VALID 未评分），而把 `asOfTs` 设在每个身份的第 90 天之
  后时，每个单元格的未评分计数均为零。估计量、混合先验、
  三分位分层、c_s = q99 与 0.975 后验标准原样照搬实验室；
  参考拟合经模块自身的 `fitFromDailySeries` 运行。
- **D3 (C30，窗口语义）。** 实验室对每条轨迹评分一个固定
  的 90 天窗口；SDK 评分结束于身份最近事件日的尾随 90 天
  窗口（真实服务的必需）。在实验室的 90 天轨迹上，两者选
  出同一组访问日，区间 CV 除以总体计数与实验室代码完全
  一致--复测没有记录到其他评分差异，tau 未重新拟合。
- **D4 (C35，诱饵 id 空间）。** 一项表征选择，已在复测记
  录中声明：经 SDK, NAV 单元格用 id 2000..2059 声明其 60
  个诱饵--一个在合法宇宙 0..1999 之外的诱饵 id 空间，与
  实验室模型（诱饵是合法资源宇宙之外的资源）相匹配--而
  ENUM/LEARN 单元格以遍历者的枚举值作为资源 id 喂入，以
  声明的 trial 抽取位置作为诱饵集，实验室的触碰定义（资
  源属于 S）不变。NAV 的总请求数（1,116,264）与实验室运
  行（1,115,408 / 1,112,209）的差异仅源于人群种子不同，
  样本规模相同。
- **D5 (C39, harness 表征）。** 三个表征层移植，算术不变：
  实验室的两个密钥变为带不同 host 密钥的两个 SDK 实例，
  每次重复抽取一组由该次重复的单元格共享的新鲜带标准数
  据集（成对的--比实验室的单一固定数据集更严格）；两步链
  单元格在表征层除以 1.07，因为 SDK API 没有尺度参数，而
  实验室在其检查器内除；汇集单元格把每个版本的低层子集
  喂给单个实例的版本验证器、共用一个版本 id，与实验室汇
  集池的构造相匹配（所有汇集数据集在同一个密钥标签下标
  记，记录 id 跨版本重复）。
- **D6 (C29，表面下限）。** 实验室设计只说该统计量需要大
  人群；模块把它变成一个数字--`minIdentityDays`，默认
  2,000 个 identity-day，低于此人群报告为未评分--并验证
  缺口为 [4, 60] 中的整数，正是实验室直方图的支撑域。每个
  被复测的人群都远高于该下限；估计器、自助法与裁决规律原
  样照搬实验室。

没有一个偏差改变阈值、标准或裁决规律；每一个都是移植的
必需，且在可测处已测量。

## 第 9 部分 - 2.7.2 不声称什么

- **对五个模块中的任何一个都不作真实流量结论。** 上文每
  个数字都是实验室生成器家族上的模拟（每个候选一个合法
  家族），并在发布的代码上重新测量。farm 校准门（约
  11 月 16 日）仍然是它们全部的第一次真实流量检查，与
  2.7.1 的信号完全一样。
- **不执行。** 五个模块全部是咨询性的：每个输出都带
  `enforcement: "none"`，没有拦截表面，SDK 不附加任何后
  果。host 拿一面旗帜做什么，是 host 的政策问题。
- **不覆盖被排除的形态。** 前期冲量 (C27)、亚日轮询
  (C30)、发现表面泄漏 (C35)、软校准与低于数据下限的人群
  (C29)，以及重新计算或被内部人剥离的总计 (C39)，按构造
  在各自结论之外，而合成谱系形态 (R14) 在本版中不作声
  称--它的移植未通过复测（第 7 部分），任何回归都需要针
  对其校准机制的新注册。
- **不作组合结论。** 五个信号是一个一个测量的。它们的旗
  帜在同一个人群上如何相关--以及当两个同时触发时 host
  应得出什么结论--从未端到端测量过。
- **经典轮次仅覆盖默认路径。** 新模块未接入 harness 应用；
  它们的证据是实验室记录加 SDK 复测，而本轮次的"没有新
  增回归"裁决是关于本版之前就存在的那些路径的。
