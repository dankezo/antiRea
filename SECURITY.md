# Security policy

**Status:** beta. No formal third-party audit or production guarantee. For vulnerabilities, do not publish exploit details in a public issue before coordination. Use a GitHub private vulnerability report (repository Security → Advisories → Report a vulnerability) if enabled, or contact the maintainer via the contact already published in package metadata/commit profile. Include affected version, reproduction and potential impact. Do not submit private credentials or real user records.

This repository is for **authorized defensive work**. The default policy is no automatic bans, no destructive browser traps, no covert keyboard monitoring and no agent sabotage.
